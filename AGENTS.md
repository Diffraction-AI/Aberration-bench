# Aberration-bench

Aberration-bench evaluates autonomous UI review. It is maintained by Diffraction,
which is also a participant; credibility requires equal treatment of competitors.

- Never convert a hypothesis about quality, cost, or speed into a benchmark result.
- Keep non-secret configuration in versioned files. Only credentials belong in env.
- Keep case labels, reproduction oracles and adjudication outside agent environments.
- Never admit a case from a merged PR alone. Verify the symptom and its control.
- Preserve failures, unknown costs, repeated trials and all declared participants.
- Public historical cases are development data, not an uncontaminated holdout.
- Do not change the rubric, prompt or case selection after seeing release results.
- Preserve MIT licensing and upstream attribution; do not copy private product code.
- `npm run check` is the local validation gate. No paid inference is part of it.
